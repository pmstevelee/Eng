# 블로그 키워드 제안 — 현재시제의 쓰임

네이버 블로그 글을 쓰기 전에 고른 키워드예요. 바꾸고 싶으면 아래 **선정** 블록만 고친 뒤 `npm run blog -- {slug} --force`로 원고를 다시 만들어요.

## 선정

```keywords
메인: 현재시제 쓰임
서브: 현재시제 예문, 현재시제 부정문, 현재시제 의문문, 현재시제 3인칭 단수, 현재시제 습관
```

- **메인 키워드를 고른 이유:** ‘현재시제 쓰임’은 네이버에서 실제로 많이 검색되는 키워드이며, 강의의 핵심 주제(현재시제의 4가지 쓰임)와 정확하게 일치합니다. 검색자의 의도(언제, 어떤 상황에 현재시제를 써야 하는지 궁금함)와 강의 내용이 완벽하게 맞닿아 있습니다.
- **서브 키워드를 고른 이유:** ‘현재시제 예문’, ‘부정문’, ‘의문문’, ‘3인칭 단수’, ‘습관’은 실제 네이버 검색에서 현재시제와 함께 자주 검색되는 롱테일 키워드입니다. 각각 강의의 예문, 문장 공식, 실수 방지, 실제 쓰임(습관) 등과 연결되어 검색자와 강의 내용 모두를 만족시킵니다.
