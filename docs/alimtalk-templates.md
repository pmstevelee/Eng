# 알림톡 템플릿 검수 신청 문구

학부모 알림(상담관리 2단계 B)에서 사용하는 카카오 알림톡 템플릿 5종입니다.
(5번 `INQUIRY_RECEIVED`는 3단계 C 외부 상담신청 폼의 접수 확인용 — 학원 설정에서 켠 경우에만 발송)
SOLAPI 콘솔 > 카카오 > 알림톡 템플릿에서 아래 문구 그대로 등록·검수 신청하세요.

> ⚠️ 알림톡은 검수를 통과한 문구·변수와 발송 요청이 **정확히 일치**해야 발송됩니다.
> 이 문서의 본문은 코드(`src/lib/notifications/templates.ts`)에서 그대로 생성했습니다.
> 문구를 바꾸려면 코드와 이 문서를 함께 수정하고 재검수를 받아야 합니다.

## 공통 설정

| 항목 | 값 |
|---|---|
| 메시지 유형 | 기본형 (정보성) |
| 강조 유형 | 선택 안 함 |
| 카테고리 | 교육 > 학원 (콘솔 목록에서 가장 가까운 항목 선택) |
| 보안 템플릿 | 아니오 |
| 버튼 | 없음 (링크는 본문 변수로 전달) |

- 검수 통과 후 발급된 **템플릿 ID**를 각 항목의 환경변수에 넣으면 알림톡으로 발송됩니다.
- 템플릿 ID가 비어 있으면 같은 문구가 **SMS/LMS 문자**로 발송됩니다 (검수 대기 중에도 사용 가능).
- 알림톡 발송 실패 시 SOLAPI가 같은 내용을 SMS/LMS로 **대체발송**합니다.
- 링크를 버튼으로 받고 싶다면 "웹링크" 버튼(링크에 변수 사용)으로 등록할 수 있지만, 그 경우 발송 코드도 버튼 형식으로 바꿔야 합니다.

## 변수 값 형식

| 변수 | 형식 예시 |
|---|---|
| `#{학원명}` | 위고업잉글리시 (지점은 "위고업잉글리시 동탄점") |
| `#{학생명}` | 김하늘 |
| `#{일시}` | 9월 26일 (토) 오후 4:00 |
| `#{학원연락처}` | 031-123-4567 (학원 정보에 번호가 없으면 "학원 대표번호") |
| `#{응시링크}` | https://login.wegoupenglish.com/placement/invite/… |
| `#{마감일}` | 10월 2일 (금) |
| `#{결과링크}` | https://login.wegoupenglish.com/placement/result/… |

## 1. 상담 예약 확정 (`APPOINTMENT_CONFIRMED`)

- 환경변수: `SOLAPI_TEMPLATE_APPOINTMENT_CONFIRMED`
- 변수: `#{학원명}`, `#{학생명}`, `#{일시}`, `#{학원연락처}`

**템플릿 본문 (검수 신청 문구)**

```
[#{학원명}] 상담 예약 안내

안녕하세요, #{학원명}입니다.
#{학생명} 학생의 상담 예약이 확정되었습니다.

■ 일시: #{일시}

일정 변경이 필요하시면 아래 번호로 연락 부탁드립니다.
☎ #{학원연락처}
```

**발송 예시**

```
[위고업잉글리시] 상담 예약 안내

안녕하세요, 위고업잉글리시입니다.
김하늘 학생의 상담 예약이 확정되었습니다.

■ 일시: 9월 26일 (토) 오후 4:00

일정 변경이 필요하시면 아래 번호로 연락 부탁드립니다.
☎ 031-123-4567
```

## 5. 상담 신청 접수 확인 (`INQUIRY_RECEIVED`)

- 환경변수: `SOLAPI_TEMPLATE_INQUIRY_RECEIVED`
- 변수: `#{학원명}`, `#{학생명}`
- 발송 시점: 외부 상담신청 폼(`/apply/{학원주소}`) 제출 직후. 학원 설정 > 상담관리 > "접수 확인 알림 발송"을 켠 학원만.
- 같은 번호로 다시 신청(재문의)해도 동일하게 발송됩니다 (신규/중복 여부를 신청자에게 드러내지 않기 위해).

**템플릿 본문 (검수 신청 문구)**

```
[#{학원명}] 상담 신청 접수 안내

안녕하세요, #{학원명}입니다.
#{학생명} 학생의 상담 신청이 정상적으로 접수되었습니다.

담당 선생님이 확인 후 연락드리겠습니다.
감사합니다.
```

**발송 예시**

```
[위고업잉글리시] 상담 신청 접수 안내

안녕하세요, 위고업잉글리시입니다.
김하늘 학생의 상담 신청이 정상적으로 접수되었습니다.

담당 선생님이 확인 후 연락드리겠습니다.
감사합니다.
```
